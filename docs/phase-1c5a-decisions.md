# Phase 1C.5A Decisions

Status: implemented locally; not committed, deployed, or applied to static v7.

## Accepted

- The platform direction is a scholarly field guide for mathematical language.
- The existing navy, pale blue, saffron, and coral identity is retained and
  converted into semantic tokens.
- The graph-paper vocabulary trail is the single signature motif.
- System fonts remain the dependable default; no external font request occurs.
- The design system stays inside `apps/platform-web`; a published component
  package would be premature.
- Light mode is implemented while semantic tokens preserve a future dark-mode path.
- The teacher shell adds local navigation only across already-existing preview routes.
- Empty teacher, class, report, account, and entitlement states remain truthful.
- Stable visual snapshots cover a mobile vocabulary board, desktop product-path
  grid, and Smart Board launch panel rather than brittle full pages.

## Explicitly deferred

- Full marketing-site information architecture and content.
- Real teacher workflows, accounts, persistence, classes, reports, or billing.
- Dark mode and user-selectable themes.
- A final logo, trademark work, favicon, or installed app assets.
- A published component package or external UI framework.
- Any restyling or migration of the canonical v7 game.

## Owner decisions remaining

- Final logo and favicon direction.
- Whether a licensed typeface creates enough educational-brand value.
- Dark-mode priority and testing requirements.
- Phase 1C.5B marketing content scope and approved claims.
- Final teacher-workspace navigation after real workflows are specified.
