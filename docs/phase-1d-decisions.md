# Phase 1D decisions

Accepted for the local vertical slice: teacher-only email/password Auth with verification and recovery; Auth users plus a separate profile; active/suspended/deletion-requested states; request-only deletion; owner-scoped classes and activity drafts; one minimum stored game mode (`team-hunt`); publicly readable safe active products; teacher-readable but non-writable own entitlements; new accounts receive no entitlement; deletion-requested accounts become read-only for status/request and lose teacher-data writes.

Explicitly deferred pending owner approval: permanent deletion, students or rosters, organization tenancy, final paid policy, automatic premium grants, Stripe/billing, more game modes, managed sessions, stored reports/performance data, relaxed suspension/deletion restrictions, hosted Supabase linking, production deployment, and any canonical v7 or vocabulary change.
