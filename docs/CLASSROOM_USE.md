# Classroom Use

1. Open Trace Clash on the computer connected to your Smart Board.
2. Choose **Quick Play** for immediate defaults, **Classroom Match** for two
   configured teams, or **Tournament** for 2–8 teams.
3. Complete or skip the score-free first-run practice.
4. For a configured match, enter team names and choose a winning score.
5. Choose Easy, Medium, Hard, or Mixed.
6. Select **Start New Match**, then invite Team A to the board.
7. The timer is stopped on the **Ready?** screen. Select **Start Turn** only when the student is in place.
8. After Team A finishes, pass the board to Team B. Team B receives the identical puzzle with a fresh timer.
9. The game compares results and updates the score.

Use **Pause** if the class needs attention. **Restart Attempt** clears only the line; the current timer keeps running. In **Teacher Menu**, **Restart Turn** restores the full timer, **Skip Puzzle** awards no points, and **End Game** requires confirmation.

Hints progress through the endpoint rule, one highlighted start, the first
legal edge, and one additional legal move. Node Mode lets a player select
connected nodes instead of dragging continuously.
