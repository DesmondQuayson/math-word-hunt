# MathNexa v1.2.66 — Online Math Prep covers Grades 1–8

Released 2026-11-24 (UTC) under explicit owner approval. Staging and production were built from the same commit.

The owner's decisions, given in this session on 2026-11-24:
- the `/about` heading says Grades 1–8;
- push and open the pull request once the local checks pass;
- release "if every check passes";
- after the WebKit runs could not start on the release machine (see Release gates), "Release without WebKit".

Why: ShowMe (Online Math Prep) added Grades 1 and 2 in ShowMe v1.2.25 (released 2026-11-23). MathNexa still said
Online Math Prep covers Grades 3–8. This is a wording release only: no logic, data, environment, dependency,
billing or access change.

What changed:
- **`64d1a3e`:** every statement about Online Math Prep's grade coverage now says Grades 1–8.
  - **Homepage:** the eyebrow, hero description, Online Math Prep card title and card note. The hero sentence is also
    the default meta, og and twitter description and the homepage JSON-LD description, so those change too.
  - **`/about`:** the title, meta description and the Online Math Prep entry.
  - **`/online-math-prep`:** the eyebrow, H1, description and SEO title/description, and the section now reads
    "Grades 1 to 8 · Eight grade levels, from Grade 1 to Grade 8".
  - **`/map-prep`:** the "not configured" fallback header.
  - **Link-preview card:** regenerated by `scripts/build-share-image.mjs`.
  - **Tests:** the matching unit and e2e assertions.
- **`3c65b22`:** the link-preview card moved to a new file name, `/media/social/mathnexa-share-grades-1-8.png`, so
  previews cached with the Grades 3–8 card are fetched again. The old name serves the same new card.
- **`9ff200d`:**
  - The `/about` heading now reads "Online math resources for Grades 1–8 teachers and families" (owner decision).
  - A unit test pins it, along with the Online Math Prep entry, and checks that only the Missouri note keeps
    Grades 3–8. It fails against the old heading.
  - The positioning comment and the two homepage positioning records got dated addenda.
- **`a1f18a3`:** the five phase 9 homepage baselines were regenerated. The image sizes are unchanged, and each image
  differs in exactly four glyph-sized areas (0.008–0.019% of pixels): the "3" that became "1".

Kept on purpose:
- the Missouri alignment note ("MAP-style Grades 3–8"), because the MAP Grade-Level Assessment covers Grades 3–8;
- the grade bands of individual games;
- teacher class grades 6–8;
- the owner-approved audience line ("… and middle school math review").

These areas are unchanged:
- everything in v1.2.65: Web Analytics (still off), the Google tag, consent, sign-up, trial eligibility, emails,
  pricing, Checkout, the webhook, entitlements, Super Admin and Google Ads conversions;

## Wording audit (before the release)

A read-only multi-agent sweep of the repository, the live site, ShowMe's source and the owner's marketing materials
found no other runtime statement of Online Math Prep coverage as Grades 3–8. Every finding was re-checked by an
independent verifier.
- **Claims checked against ShowMe `277496e0`:** every grade 1–8 has animated lessons, guided and independent practice,
  quick checks and reviews, and appears in the worksheet generator. Every new claim holds.
- **Public CMS pages:** `/content/map-prep` carries no grade range, and the other CMS keys are unpublished (404).
- **Emails and Checkout:** no email or Checkout text names Online Math Prep's grade band.
- **Off-site material** still says Grades 3–8 and is listed for the owner below.

## Release gates (local, clean worktree, `a1f18a3`)

- **Typecheck, lint, build:** all pass (lint: 0 errors, 8 warnings).
- **Unit:** platform-core 245/245; platform-web 1,943 passed and 1 skipped, including the new `/about` test.
- **Security:** baseline 401/401. Node tests 46/47; the one failure is the WebKit case below. Rerun after a fresh
  build: same result.
- **Audits:** bundle, Number Cross, billing and phase 8H all pass.
- **Browser suites:**
  - phase 8H 1/1, phase 9 35/35 (including the regenerated homepage baselines), phase 7B 10/10, phase 7C 17/17;
  - Google Ads conversions: 32/32 in Chromium and mobile Chrome;
  - school access: 16/16 in Chromium.
- **WebKit / mobile Safari did not run.**
  - Windows Smart App Control on the release machine (enforcing) blocks Playwright WebKit's `libxml2.dll` (Code
    Integrity events 3033 and 3077), so `webkit-2336` exits at launch with code 3236495362, before any page loads.
  - Chromium launches normally.
  - This affected 32 ads runs and 8 school runs, plus the WebKit case of the protection-bypass Node test.
  - The same runs passed on this machine for v1.2.64 (2026-11-22).
  - The owner chose to release without them.
