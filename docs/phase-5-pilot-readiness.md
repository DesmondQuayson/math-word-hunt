# Phase 5 controlled teacher pilot readiness

Pilot activation is **not approved**. No invitations have been sent and no participants have been created.

## Entry gate

- Approved 3–10 adult-teacher list, 2–4 week dates, owner, incident owner, support channel, and response expectations.
- Approved privacy notice and visible rule: no student names, email, rosters, work, accounts, or sensitive school information.
- Restricted preview, test-mode billing disclosure, preview status/banner, unsupported-feature list, feedback form, reset cadence, rollback drill, and exit criteria verified.
- Email remains capture/sandbox only. Payments remain simulated. Permanent deletion remains dry-run/disabled.
- Each adult teacher receives onboarding for confirmation/recovery, privacy-minimized class labels, activity drafts, canonical v7 launch, test billing, issue reporting, and immediate stop instructions.

## Operations

Collect only workflow, browser/device, approximate time, impact, accessibility/Smart Board observations, and reproducible steps. Never request passwords, tokens, payment data, raw page dumps, or student information. Classify incidents with the Phase 4 severity model. Do not expand the pilot without approval.

Suspend invitations and block access for cross-account exposure, secret or real-payment risk, student-data submission, recurring data loss, inaccessible core workflow, or unmanageable support load. Use emergency deny and access restriction before investigating. Owner controls external communication.

## Exit

Success requires teacher completion of confirmation/recovery, privacy-minimized planning, canonical game play on target devices, comprehension of limits/status, and no blocking security/accessibility failure. At exit, stop invitations, export only minimized feedback/evidence, process adult deletion requests under the staged non-permanent policy, reset/dispose preview data after approval, revoke bypass and pilot access, remove test webhook/redirects, and record the pilot decision. Public production launch is a separate future decision.
